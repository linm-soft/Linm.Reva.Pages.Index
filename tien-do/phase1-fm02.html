Thuộc quyền Linm

ERP Service — Release & Deploy

Linm bàn giao bản build triển khai và hướng dẫn deploy hệ thống ERP (không chuyển giao full source lõi platform).

  • Docker image / release build — Linm.Web.ERP.WebService (API + BFF + jobs host)
  • Hướng dẫn deploy — docker-compose.yml · .env.template · migration gate
  • MFE ERP build — Finance · Sales · Analytics · Master · HR · Supply (artifact npm/webpack)
  • Shell host — MFE-CORE Root-App mount route ERP
  • Tài liệu vận hành service — configuration · tenant · platform jobs (khung chung)

Nghiệm thu: service chạy ổn định pilot FM02 · báo cáo/danh mục/chứng từ truy cập được qua build đã deploy.

Thuộc quyền FM

Prefix FM · Job sync POS — Full source

FM nhận toàn bộ mã nguồn tích hợp, ETL, mapping, job đồng bộ POS và báo cáo quản trị — kèm hướng dẫn cấu trúc source và hướng dẫn triển khai lớp tích hợp.

  • Job service (tách release) — Linm.Reva.WebService/Jobs — sync POS độc lập · Docker + deploy guide
  • Repo dữ liệu & đối soát — Linm.Reva.Data (master CSV, scripts, spec Phase 1)
  • MFE báo cáo quản trị — Linm.Web.Reva.Report (/reva/bao-cao/*)
  • Job sync POS → ERP — connector reva-fm-hoa-don · reva-fm-phieu-thu · reva-fm-phieu-chi (đang tách sang Linm.Reva.WebService/Jobs)
  • Converter & mapping — RevaFmPayloadConverter · RevaFmMappingRegistry · lookup định khoản FM
  • Master sets FM — data/master/sets/reva-* (NCC, materials, posting rules, PNM T12…)
  • Script đối soát — reconcile-pos-*.mjs · output doi-soat-12-2025/
  • Tài liệu — source structure · hướng dẫn triển khai connector/job · runbook sync

Nghiệm thu: FM tự build/deploy lớp tích hợp · chỉnh mapping · mở rộng sync 12 CH theo tài liệu bàn giao.
