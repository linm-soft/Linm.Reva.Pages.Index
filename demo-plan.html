3

Demo import file sao kê ngân hàng và tạo đối tượng

15 phút

Trình diễn quy trình import file sao kê ngân hàng theo 3 khung giờ trong ngày (8:30 · 14:00 · 16:50). Hệ thống tự động sinh chứng từ báo có, báo nợ, ủy nhiệm chi, chuyển tiền nội bộ từ file sao kê. Đây là tính năng trọng tâm giúp FM giảm thiểu thời gian nhập liệu ngân hàng thủ công.

📄 Upload file sao kê CSVKéo thả file · Xem trước dữ liệu · Validate cột bắt buộc · Mapping tự động
🔄 Import wizard 4 bướcUpload → Validate → Phân loại (BC/BN/UNC/CTNB) → Import · Dry-run trước khi import thật
🤖 Tự động tạo chứng từSinh BC/BN/UNC theo từng giao dịch · Gán tài khoản ngân hàng · Định khoản nghiệp vụ
🏷️ Tạo đối tượng từ sao kêTrích xuất tên nhà cung cấp/khách hàng từ nội dung giao dịch · Tạo mới hoặc gắn với đối tượng có sẵn
8:30Đầu ngày · Tồn ngày hôm trước
14:00Giữa ngày · Giao dịch trong ngày
16:50Cuối ngày · Chốt số liệu
Kết quả thực tế: 62.800+ giao dịch sao kê từ nhiều ngân hàng đã được import dry-run thành công (30.500 BC, 29.600 UNC, 1.700 CTNB). Import thực tế sẵn sàng với lịch trình: 8:30 (tồn trước) · 14:00 (trong ngày) · 16:50 (cuối ngày).
